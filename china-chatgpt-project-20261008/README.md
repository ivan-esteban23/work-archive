# China Trip — ChatGPT project setup

Prepared 8 October 2026 from the current China notes in your Obsidian vault. Suggested project name: **China Trip — Planning & Research**. No travel year is selected.

## Set it up

1. Create a ChatGPT project with the suggested name.
2. Open the project’s instructions field and paste the complete contents of [project-instructions.txt](project-instructions.txt).
3. Add the **five individual `.txt` files** in [sources](sources/) to the project’s Sources area. If you downloaded the ZIP, extract it first; it is a delivery bundle, not the source file to upload. Keep the instructions and this setup guide out of the sources to avoid duplicate context.
4. Start a chat inside that project and paste [first-message.txt](first-message.txt).

Projects share uploaded sources and instructions across their chats. A ChatGPT project does not automatically have access to your local Obsidian folder. [Official OpenAI project documentation](https://learn.chatgpt.com/docs/projects?surface=app), checked 8 October 2026. Exact controls can differ by app version; this session did not create the project or test uploads in your account.

## Keep it current

These uploads are snapshots. After decisions change, save a dated decision update in the project, including what it replaces. When the Obsidian guide changes materially, regenerate the relevant source files and replace the older uploads to avoid conflicting copies. When asking Codex to update the vault, supply decisions or new research from the ChatGPT project; the two copies do not synchronize automatically.

Separate chats can focus on route/season, food and tea, photography/shopping, transport/hotels, and preparation. Keep confirmed reservations distinct from the research shortlist. The uploaded reservation ledger is empty as of this snapshot.

The `export-manifest.json` records original note hashes and generated file hashes for this export. No current provider fact was revalidated merely by exporting these notes.
