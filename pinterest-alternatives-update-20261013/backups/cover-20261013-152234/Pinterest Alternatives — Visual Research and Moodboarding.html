03 / FROM DISCOVERY TO DIRECTION

Build a board with a purpose.

  1. Define the visual question

    Choose one subject per board: a silhouette, fabric, styling detail, palette or page treatment.

  2. Collect with context

    Save the original page or creator post, image credit, publication date, country/city, and the styling detail you want to study.

  3. Compare references

    Use several independent examples. Keep runway, street photography, product listings, historical objects and AI interpretations visibly separate.

  4. Build the board

    Group by silhouette, material, palette and accessory. Add a sentence explaining each selection instead of collecting lookalikes without context.

  5. Keep the final record in Obsidian

    Store permitted local copies with the source record; revisit the original page before publication. A collection link alone is not a durable backup.
