# Pinterest Alternatives — Visual Research & Moodboarding

Collected 2026-10-13. Grouped by use case; fashion picks matter most for the Asia Fashion Visual Guide project.

## Fashion / street-style sources

- [We Heart It](https://weheartit.com) — closest Pinterest vibe, heavy on aesthetic/soft-style imagery
- [Poizon / Dewu](https://www.dewu.com) — Chinese sneaker/streetwear community; best source found for Asian micro-aesthetics (outfit posts, not product listings)
- [Xiaohongshu / 小红书](https://www.xiaohongshu.com) — Chinese lifestyle app; strongest for Xin Zhongshi, Acubi, Fairy Grunge-type references
- [Vogue Runway](https://www.vogue.com/runway) — full seasonal runway archives, editorial-grade references
- [Vestiaire Collective](https://www.vestiairecollective.com) — curated secondhand luxury; useful for garment-detail references

## Moodboarding / visual bookmarking

- [Are.na](https://www.are.na) — designer-oriented boards, low algorithmic noise, links persist (no pin rot)
- [Cosmos](https://cosmos.so) — Pinterest-like, aimed at creatives, strong curation
- [Raindrop.io](https://raindrop.io) — bookmark manager with card previews; good for keeping source URLs + credits together
- [Milanote](https://milanote.com) — visual boards with notes, design-team oriented
- [FigJam](https://www.figma.com/figjam/) — freeform boards from Figma; better for collab canvases than image discovery

## Open-source / self-hosted

- [Linkwarden](https://linkwarden.app) — self-hosted visual bookmarking, you control the data
- [Shaarli](https://github.com/shaarli/Shaarli) — minimal self-hosted link/image bookmarking (its shaarli.org site currently serves an invalid TLS cert, so the GitHub repo is the reliable entry point)

## Notes for the fashion guide workflow

- Pinterest hotlinks are blocked and pins rot constantly — saving **source URL + credit + retrieval date** (as in `images/references/CREDITS.md`) avoids redoing verification later.
- Are.na or Cosmos for collecting, Raindrop for URL/credit tracking beats Pinterest for this pipeline.
