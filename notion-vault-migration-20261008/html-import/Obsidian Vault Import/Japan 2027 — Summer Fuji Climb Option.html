The hut replaces a hotel night; it is not an extra uncounted night. Luggage storage/forwarding and transport after descent require confirmation. A sunrise summit is optional, not a reason to climb through the night without rest. The official Yoshida model plan provides a starting reference for a hut-based climb; a guide/operator should settle the route, pace, and suitability if selected.
