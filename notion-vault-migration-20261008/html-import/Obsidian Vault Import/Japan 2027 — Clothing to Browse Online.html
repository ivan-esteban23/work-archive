How to check a candidate yourself

  1. Open the Japan product link; use browser translation if helpful.
  2. Select the color and size and inspect the current stock message. サイズ means size; カラー means color.
  3. Open the size chart, サイズ表. Compare body and finished-garment measurements separately: 身幅 is flat garment width; 肩幅 is shoulder width; ウエスト is waist; 股下 is inseam.
  4. For a branch visit, use 店舗在庫状況 / 店舗の在庫を確認する (store inventory), choose the exact store, and record the result and date. A generic nearby-store message without a selected branch is inconclusive.
  5. Recheck close to your visit; try on L/XL tops and the candidate trouser sizes where fitting is available. Check the applicable return terms before paying.
