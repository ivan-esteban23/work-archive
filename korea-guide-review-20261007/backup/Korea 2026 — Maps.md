# 📍 Korea 2026 — Maps index

[[Korea 2026 — Start Here|← Dashboard]] · [[Korea 2026 — Map View|🗺️ Interactive maps]] · [[Korea 2026 — Cafés and Shops|Shops and cafés]] · [[Korea 2026 — Itinerary|Itinerary]]

**Every Google Maps search in this trip, in one place.** Each link uses Google's search format — `maps/search/?api=1&query=<Korean name + place>` — rather than a fixed place ID, because a pinned ID can drift to the wrong branch while a name search always re-resolves.

> [!tip] Why search links and not pins
> A place-ID URL is a hard address to one building. If the shop moves or has two branches with the same name, it sends you to the wrong one or nowhere. Searching the **Korean name plus the district** is slower to type and far more reliable, and it works even if the listing you saw was from a different app.

> [!warning] Check the same morning, on the ground
> For anything small — a vintage stall, an independent bookshop, a tea house — open Naver Map or Google Maps before you walk across the city. Hours change weekly in this layer of shops.
