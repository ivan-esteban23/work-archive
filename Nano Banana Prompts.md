Original numbering, titles, and repeated entries are retained. The original file is unchanged. These are wording adaptations based on Google's image-prompting guidance, with image-generation comparison tests still pending.

## Use

Copy one prompt's text block into Nano Banana. Reference images are optional. To use one, open the reference link, download the image, and attach the image separately. Markdown links do not upload an image to the generator. The optional reference instruction sits outside each text block so standalone generation never assumes an attachment.

Set the desired aspect ratio through the image tool's controls when available, while retaining the crop described in the selected prompt. Full-outfit prompts need enough space for all specified footwear and accessories.
