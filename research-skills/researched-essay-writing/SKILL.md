---
name: researched-essay-writing
description: Write or revise a detailed essay or explanatory report using supplied material and verified sources. Use when the user wants connected long-form analysis, including travel essays, rather than a short answer or itinerary alone.
---

Produce a coherent essay that develops a central question or argument with evidence. Respect the requested language, audience, length, and format. If unspecified, choose a length that covers the subject adequately without padding; for a supplemental travel-project essay, roughly 900–1500 words is a starting point, not a requirement.

- Read the user's supplied guide and relevant current notes. Separate personal preferences and proposed plans from independently established facts. Historical recaps provide context, not automatic authority over newer decisions.
- Decide what the essay should help the reader understand. Organize paragraphs around that purpose, rather than writing one paragraph per search result. Use headings when they help navigate a substantial artifact.
- For factual essays, verify important claims using actual source pages or supplied documents before drafting. If the source-checked-web-research skill is available, use it for substantial new research; otherwise perform that research with available tools. Do not invent evidence to fill an outline.
- Build connected prose: make a point, explain the supporting evidence, and show its implication for the reader. Compare alternatives and explain meaningful tradeoffs. Avoid generic introductions, promotional language, repetitive conclusions, and unnecessary lists.
- Place source links or the requested citation style next to supported claims. Include only sources actually used. Paraphrase responsibly; quote sparingly and within applicable limits. Make interpretations and recommendations identifiable as judgments.
- For travel, connect culture, season, geography, transport, budget, and the user's interests where relevant. Explain how optional destinations would affect the proposed route instead of silently adding them. Label future availability and unconfirmed costs clearly.
- Revise for a clear argument, transitions, repetition, contradictory figures, unsupported specifics, and citations that truly support the associated claim. Preserve the user's voice when editing existing prose.
- Save the artifact in the requested format and location when authorized. For ChatGPT project sources, prepare a clearly named UTF-8 Markdown or text file with a research date and source links. State whether it was only saved locally or actually uploaded; never imply automatic synchronization with an Obsidian vault or ChatGPT project.
