## Saved changes

- **Current typography:** Newsreader for editorial serif text and Inter for sans serif text and controls. Official variable fonts embedded with SIL Open Font Licenses, including offline viewing; optical sizing enabled. Existing Chinese/Japanese/Korean fallbacks retained.

- **Font pairing:** Times New Roman for serif text and Arial for sans serif text, including all language-specific stacks with existing CJK fallbacks. Removed unused embedded fonts, updated translated credits and versioned the offline cache.

- **Appearance header:** new top header with Light/Dark buttons, translated in all six languages. The selected theme is saved in this browser and restored before first paint. System preference applies until a manual choice is made. Native controls and browser-toolbar color follow the selection. Offline shell cache updated.

- **Interaction and accessibility:** shared 140 ms feedback for controls and disclosure indicators, comprehensive reduced-motion handling, retained keyboard focus, minimum 48 px controls, and enlarged-text reflow for results/reset, source metadata, footer and dialog headings. Essential information remains available without hover; all content and application JavaScript preserved.

- **Editorial sections:** source names first in editor picks, secondary supporting labels, directory-matched surfaces/padding/hover/focus, clearer route source names, consistent shortlist/workflow/reference-note spacing, readable footer copy and shared dialog typography/surfaces. All source links, route steps and workflow order preserved; introductions retained.

- **Navigation and filters:** search-first controls with nearby results count and reset; category → country → coverage → access; selected states and removable chips; mobile category dropdown; collapsible section links/country shortcuts; sticky-search focus protection and static search in short landscape viewports.

- **Source cards:** unified hierarchy (logo/name → purpose → metadata → detail disclosure → actions), quieter readable category/country/access information, aligned Save/Copy actions, consistent 40 px logos/initial badges, subtle hover and clear keyboard focus. Existing descriptions, access notes, evidence links and original image assets preserved.

- **Layout and spacing:** unified spacing scale; more breathing room around the masthead, cover, section introductions and card groups; shared aligned gutters; one column below 640 px, two from 640–1199 px, and three from 1200 px. Removed enclosing card/filter/editor/route borders while preserving essential control boundaries and occasional fine section rules.

- Added Booooooom, Colossal, IGNANT, Frieze, The Met Collection and Rijksmuseum Collection, bringing the directory to 58 sources.
- Alphabetized all website source cards, editor picks, routes, category filters, coverage/access choices, navigation links and independent reading topics. Workflow instructions keep their logical step order.
- Retained Instrument Serif and Source Sans 3; refined headline/body scale, source-title weight, supporting text and multilingual font stacks.
- Applied warm ivory, soft white, charcoal, warm gray, pale stone and muted bronze. Essential control boundaries use a darker stone shade; dark mode uses a lighter bronze accent.
- Updated app theme colors and offline cache version. Existing favorites remain URL-based and local to each browser/device.

## Verification and limits

Latest layout checks covered 42 screen-width/language combinations (320, 390, 640, 768, 1000, 1200, 1440 px × six languages), including expanded source details and research routes. Checked column counts and alignment of headings, controls and cards. Earlier typography checks covered 24 combinations, light/dark screenshots, A–Z ordering, search/country filters, and favorite persistence. Checked 34 palette contrast pairings plus computed control-border and selected-hover states. These focused checks do not establish full WCAG conformance.

CJK fonts use regional system fallbacks and can vary by device. Physical-device installation and offline mode were not retested during these design passes. The local HTML is self-contained for its visual assets and avoids service-worker registration under `file://`; linked external sources require internet. This copied snapshot does not automatically synchronize with the hosted website. No Obsidian in-app rendering test was performed.

Source-review dates remain per source; the UI update does not constitute fresh research of all providers. The historical country audit remains dated 13 October; new-source country evidence is included in the research directory.
