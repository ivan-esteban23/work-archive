# South Korea Trip — ChatGPT upload package

Prepared 8 October 2026. These files are saved locally. No native ChatGPT project was created and nothing was uploaded; the available tools do not provide those actions.

1. Create a separate ChatGPT project named **South Korea Trip**.
2. Add `Korea — Current Planning Brief and Verified Sources.md` and `Korea — Travel Essay and Verified Sources.txt` to its Sources section.
3. Paste `Project Instructions.txt` into the project's instructions.
4. Optionally add `Korea — All Guide Notes Snapshot.md` for the complete guide. It includes historical sections; the current brief takes precedence.
5. Start a project chat with: “Compare spring and autumn scenarios for a solo 9–10-night South Korea trip within my US$2,500 ground budget. Keep international airfare separate and dates provisional.”

[OpenAI's project documentation](https://learn.chatgpt.com/docs/projects) explains shared project sources and instructions. The source files are snapshots; saving a local vault note does not upload it or refresh its ChatGPT copy. Keep the Japan project separate.

The complete snapshot retains original wiki-link text and note boundaries. ChatGPT can read the content, but the export is not a live Obsidian vault and map plugins do not render there. Prices are dated research examples, not reservations. Original notes are backed up in the sibling `backup` directory; `inventory.json` lists every reviewed note and changed file.
